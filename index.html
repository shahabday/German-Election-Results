German Election Data — Interactive Tools

Seven independent, self-contained visualizations built on real German election results (GERDA) and socioeconomic covariates (Zensus 2022, VGRdL, INKAR) — federal, European, state, and municipal elections from 1990 to 2026, at resolutions from Bundesland down to individual municipalities and constituencies.

Each tool below is a standalone page with its own data — nothing shared at runtime, nothing that breaks if you only deploy some of them.

Data: GERDA (Heddesheimer, Hilbig, Sichart & Wiedemann, 2025, Nature Scientific Data) · Zensus 2022 · VGRdL · INKAR · Boundaries: BKG VG250, m-ad/geofeatures-ags-germany

Election Results

Bundestag Wahlkreis Map

Federal election results by constituency (Wahlkreis) — the real direct-mandate map, 2002–2025.

  • Real single-winner constituency seats, not an area-level approximation
  • Erststimme (direct mandate) and Zweitstimme (party vote) toggle
  • 7 elections, each on its own real constituency boundaries

Municipality Election Map

All four election types — Bundestag, Europawahl, Landtag, Kommunalwahl — at municipality resolution, nationwide.

  • ~10,900 municipalities, 1990–2026
  • Nationwide "current standing" view for state-scheduled elections
  • Includes 2026 results not yet in most public datasets (Berlin, MV, Saxony-Anhalt, Rhineland-Palatinate)
Open tool →

Election Trends — Swing Map

Swing between consecutive elections: who's gaining, who's flipping, and which areas are close to flipping next.

  • Party growth (pp swing), flipped areas, at-risk-of-flipping, turnout change
  • "At risk of losing to [party]" — pick any party and see its trajectory
  • CDU/CSU merged as one party for swing purposes
Open tool →

Election Results — Time Series

Pick any states, counties, or municipalities and compare a party's vote share (or turnout) across every election of one type, as line charts.

  • Click the map or search by name to build a comparison
  • Hover for a quick preview line before committing
  • State-scoped for Landtag/Kommunalwahl, nationwide for Bundestag/Europawahl
Open tool →

Voting Profile — All Elections Blended

Blends all four election types into one "who does this place actually vote for" picture, over a year window you control.

  • Adjustable time window — full history vs. last 5/10 years tell very different stories
  • "Consistency" view: do national, state, and local elections even agree?
  • Surfaces real east/west and national/local voting divergence
Open tool →

Demographics & Economy

Demographics & Economy Map

Zensus 2022 census data at municipality resolution, plus county-level income and INKAR indicators as a multi-year time series.

  • 28 metrics: age structure, migration, housing, income, unemployment, rent
  • Fixed vs. dynamic color scale, and a year-over-year growth view
  • Every metric has a one-sentence explanation built in
Open tool →

Demographics — Time Series

Compare states or counties' economic and demographic indicators over time — same click/search comparison tool as the election time series.

  • Same 14 county-level metrics as the demographics map
  • Click, hover-preview, or search to build a multi-line comparison
  • Useful alongside the election trends map for "why" questions
Open tool →
Each tool is a static site: plain HTML/CSS/JS + pre-built JSON data, no server or build step required to run it. To deploy, publish each map*/ folder as-is; every tool links to its data with paths relative to its own folder, so it works from any subpath.
